# Webmu — Template Penjualan (WA / DM)

> Template outreach untuk 3 segmen target. Bahasa casual-professional.
> Prinsip BR-01: jual **hasil** (website jadi, pelanggan datang), bukan teknologi.
> Ganti `[Nama]`, `[Usaha]` saat dipakai. Nomor pengirim = nomor Webmu.

---

## 1. Toko Kue / Kuliner (contoh: bakery)

**Pembuka (dingin — belum kenal):**

> Selamat pagi, Ibu [Nama] 🍰 Saya lihat Bolu [Usaha] di Google punya ulasan bagus banget, terutama soal [sebut spesifik: bolu pandannya/kue customnya].
>
> Saya bikin website untuk usaha kuliner — contoh untuk toko kue seperti punya Ibu: [link demo bakery]
>
> Dengan website, calon pembeli yang lihat status WA Ibu bisa langsung klik ke menu + harga, tinggal pesan. Jadi dalam 48 jam usahanya kelihatan lebih profesional.
>
> Kalau Ibu berkenan, saya bisa buatkan contoh tampilan awal untuk [Usaha] gratis. Boleh?

**Follow-up (H+2, belum dibalas):**

> Ibu [Nama], izin menyapa lagi 😊 Contoh tampilan awal untuk [Usaha] sudah saya siapkan — tinggal saya kirim kalau Ibu mau lihat. Gratis kok, tidak ada komitmen apa-apa.

---

## 2. Klinik / Layanan Kesehatan

**Pembuka:**

> Selamat siang, Dokter/Bu [Nama]. Saya lihat [Nama Klinik] sudah ada di Google Maps tapi belum ada website sendiri.
>
> Saya bikin website untuk klinik — contoh: [link demo clinic]. Isinya jadwal dokter, tarif layanan, dan tombol janji temu lewat WhatsApp, jadi pasien tidak perlu tanya satu-satu lagi.
>
> Untuk klinik, informasi yang jelas itu penting untuk kepercayaan pasien baru. Kalau berkenan, saya buatkan contoh untuk [Nama Klinik] — gratis, sebagai bahan pertimbangan.

**Follow-up:**

> Bu [Nama], sekadar info — contoh website untuk [Nama Klinik] sudah saya siapkan. Mau saya kirim tautan pratinjaunya? Tidak ada biaya untuk pratinjau.

---

## 3. Vendor Pernikahan / Jasa Event

**Pembuka:**

> Halo [Nama]! Saya lihat karya [Nama Vendor] di Instagram bagus-bagus banget 🤍
>
> Saya bantu usaha jasa punya website sendiri — contoh untuk vendor pernikahan: [link demo wedding]. Di situ bisa tampil paket harga, portfolio, dan tombol konsultasi, jadi calon klien yang serius langsung WhatsApp tanpa perlu DM-an dulu.
>
> Biasanya calon klien banding-bandingin vendor, dan yang punya website kelihatan lebih bisa dipercaya. Mau saya buatkan contoh tampilan untuk [Nama Vendor]? Gratis, tinggal lihat dulu.

**Follow-up:**

> [Nama], contoh tampilan awal untuk [Nama Vendor] sudah jadi nih. Mau saya kirim? Siapa tahu cocok buat bantu closing klien yang sedang survey vendor 😊

---

## Nomor & Format Pesan

- **Jam kirim terbaik:** Selasa–Jumat, 09.00–11.00 atau 14.00–16.00 (hindari Senin pagi & weekend)
- **Volume aman:** 5–10 DM/WA per hari per akun (bukan spam, personalisasi selalu)
- **Sumber prospek:** ulasan Google Maps usaha lokal, Instagram tagged #lokaltoko, grup UMKM
- **Patokan konversi:** 40–200 kontak → 8–20 balasan → 2–5 minat → 1–2 closing/bulan = on-track unit economics (lihat `product-spec.md`)

## Handling Pertanyaan Umum

**"Berapa harganya?"**
> Mulai Rp 400rb sekali bayar untuk satu halaman lengkap. Paket 850rb kalau mau sampai 3 halaman + galeri + maps. Semua harga saya kirim tertulis sebelum order, tidak ada biaya tersembunyi.

**"Saya gaptek, bisa?"**
> Justru itu saya yang kerjakan semua, Pak/Bu. Ibu tinggal kirim foto usaha + daftar harga lewat WA, dua hari kemudian website-nya jadi. Sesudah itu tinggal bagikan tautannya.

**"Nanti saya bayar bulanan?"**
> Tidak ada biaya bulanan ke saya. Pembuatan sekali bayar. Kalau mau alamat sendiri seperti namausaha.com ada biaya domain tahunan sekitar Rp 150–300rb — itu ke penyedia domain, bukan ke saya, dan saya jelaskan sebelum order.

**"Bisa dilihat contohnya dulu?"**
> Bisa banget — ini 3 contoh website yang sudah jadi: [kue], [klinik], [vendor pernikahan]. Buka di HP saja biar kelihatan seperti yang dilihat pelanggan Ibu.

## Aset Before/After (untuk DM)

- Screenshot "sebelum": profil Google Maps / status WA saja (kondisi tanpa website)
- Screenshot "sesudah": `demos/screenshots/*-desktop.png` + tautan live
- Format kirim: 1 gambar gabungan (sebelah kiri sebelum, kanan sesudah) + caption 1 kalimat
