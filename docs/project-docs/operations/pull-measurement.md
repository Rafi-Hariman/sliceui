## Where to look for signal (free, no ads)

1. **Show HN** — one post, honest "what/why", ask for feedback
2. **r/webdev / r/reactjs / r/vuejs** — before/after GIF + link
3. **X** — short demo clip + tag #buildinpublic, #indiehackers
4. **Indonesian dev communities** — Facebook groups, Telegram (Webmu audience overlap)

## How this feeds the gate

- Week-12 verdict: if pull is **strong** (≥4 of 5 targets hit) → keep investing in the tool.
- If pull is **weak** → the tool hypothesis fails; fall back to the Webmu service (the cash engine) as primary.
- Do **not** conflate usage from our own demo pages (`/demos/*`) with real user pull.

## Rules

- Record evidence (screenshot/permalink), not memory.
- Update at least weekly, or when a launch post goes out.
- No paid spend — this sheet measures organic pull only (out of scope per product-spec).
