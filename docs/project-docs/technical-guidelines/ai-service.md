# Technical Guideline — AI Service

## 1. Summary
Rules for the SliceUI AI integration (`src/lib/aiService.ts`, `src/lib/prompts.ts`): the Gemini → Groq fallback chain, prompt construction, response cleaning, and handling of client-side API keys.

## 2. Scope
Applies to all code that calls AI providers or builds generation prompts. Does not cover Supabase data access (see `data-access.md`) or error messaging at the UI boundary (see `error-handling.md`).

## 3. Rules
- **R1 — Single entry point:** all AI calls go through `imageToCode(base64Image, framework, options)`. Components/hooks must not call provider SDKs directly.
- **R2 — Gemini primary, Groq fallback:** attempt Gemini first. Fall back to Groq **only** when the failure is rate/limit related (`err.status === 429` or message matches `quota`, `rate`, `limit`). Other errors rethrow.
- **R3 — Groq requires a key:** if `GROQ_API_KEY` is unset, do not attempt fallback — rethrow the Gemini error.
- **R4 — Prompt via builder only:** use `buildPrompt(framework, options)`; never inline prompt strings in callers. The builder must always include the critical output rules (code-only output, self-contained component, `// Generated by SliceUI` first line).
- **R5 — Clean responses:** strip markdown fences with `clean()` before returning. Output is a raw code string.
- **R6 — Options injection:** `ConversionOptions` toggles (`responsive`, `semanticHtml`, `darkMode`, `a11y`) are injected as instruction lines only when true.
- **R7 — Client-side keys:** read keys from `import.meta.env.VITE_GEMINI_API_KEY` / `VITE_GROQ_API_KEY`. They are public by design — never treat them as server secrets (see `security-compliance.md`). Groq client requires `dangerouslyAllowBrowser: true`.
- **R8 — No image normalization server-side:** the SPA sends the image as-is (base64 PNG). Validation (type/size) happens in `useImageUpload`, not here.

## 4. Preferred Patterns
```ts
// Preferred: one entry point, explicit fallback
const code = await imageToCode(base64, framework, options)

// Preferred: a single missing key fails fast with a clear message
if (!GEMINI_API_KEY) throw new Error("GEMINI_API_KEY is not configured")

// Preferred: provider-specific concerns live here, not in hooks
export async function imageToCode(...) {
  try { return await callGemini(...) }
  catch (err) {
    if (isRateLimit(err) && GROQ_API_KEY) return await callGroq(...)
    throw err
  }
}
```

## 5. Anti-Patterns
- ❌ Calling `gemini.getGenerativeModel(...)` or `groq.chat.completions.create(...)` from a page/hook.
- ❌ Hardcoding prompts in component code.
- ❌ Falling back to Groq on *any* error (only rate/limit errors) — masks real failures.
- ❌ Returning responses with markdown fences intact.
- ❌ Logging API keys or full prompts at error level.
