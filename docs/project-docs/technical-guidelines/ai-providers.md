# Guideline - AI Providers (Gemini + Groq)

## 1. Summary

Rules for the vision-LLM facade in `src/lib/aiService.ts` and the prompt
builder in `src/lib/prompts.ts`: the single-call model, the Gemini→Groq
fallback contract, output cleaning, and prompt composition. Inferred from
codebase.

## 2. Scope

Covers `imageToCode`, `callGemini`, `callGroq`, `clean`, `buildPrompt`, and
`getFrameworkRules`. Does not cover Supabase persistence (see
[data-access.md](./data-access.md)) or UI rendering of code.

## 3. Rules

- **R1 - One entry point.** All generation goes through `imageToCode()`. Pages
  and hooks must never instantiate Gemini/Groq directly.
- **R2 - Single multimodal call.** One request performs vision + codegen. Do
  not introduce a separate OCR/analysis stage.
- **R3 - Fallback only on rate-limit.** Switch Gemini→Groq **only** when the
  error is a rate limit/quota: `status === 429` or message matches
  `/quota|rate|limit/`. Other errors must propagate.
- **R4 - Guard the fallback.** Only call Groq if a Groq key is configured.
  Otherwise rethrow the original error.
- **R5 - Always `clean()` output.** Strip leading ```` ```lang ```` and trailing
  ```` ``` ```` fences and trim before returning/displaying code.
- **R6 - Prompt contract.** The prompt must keep the CRITICAL OUTPUT RULES
  (component-only, no fences, first line `// Generated by SliceUI`, exact text
  placeholders, hex colors, gray-div images, `/* icon: ... */` comments).
- **R7 - Framework rules are exhaustive.** `getFrameworkRules` must return a
  rule block for every framework surfaced in the picker. (Today `flutter` has a
  rule but is not in the picker - see Open Questions.)
- **R8 - Groq cap.** Keep `max_tokens` bounded (currently 4096) to control
  latency/cost.

## 4. Preferred Patterns

- Add new option toggles by pushing a rule string in `buildPrompt` (mirrors
  `responsive`/`semanticHtml`/`darkMode`/`a11y`).
- Centralize model identifiers as named constants (e.g. `GEMINI_MODEL`,
  `GROQ_MODEL`) so pinning is one edit.
- Map provider errors to user messages in the hook layer, not in `aiService`
  (keeps the service transport-pure).

## 5. Anti-Patterns

- ❌ Calling Gemini/Groq from a component or page directly.
- ❌ Falling back to Groq for non-rate-limit errors (masks real failures).
- ❌ Returning raw model text without `clean()` (leaves fences in the editor).
- ❌ Hard-coding prompt fragments outside `prompts.ts`.
- ❌ Using `gemini-flash-latest` / `pixtral-12b-2409` aliases in multiple places
  without a single constant.
